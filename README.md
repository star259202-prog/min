# 口述修圖：用說的就能修圖

這是一個類似 Lightroom Classic「修改相片（Develop）」模組的網頁修圖工具。
你只要**說出**（或打字）想調整的地方，例如：

> 「照片太暗了，陰影提亮一點，天空藍一點，膚色紅潤一點，最後加一點暗角」

它就會自動移動對應的滑桿，即時套用到照片上。

## 不會讓臉變形，也不會「AI 化」

- 所有調整都是**逐像素的色彩／光影運算**（曝光、對比、白平衡、HSL、色彩分級、清晰度等），
  跟 Lightroom 的「基本」面板一樣。
- **沒有**液化、瘦臉、大眼、磨皮美顏、換臉或任何生成式 AI 繪圖功能，照片中每個像素都留在原來的位置，
  所以五官和臉型不會改變。
- Claude（如果有啟用）只負責「聽懂你的話並決定滑桿數值」，**不會修改或重新生成照片內容**。
- 柔膚（紋理）有下限，膚色調整也很保守，避免塑膠皮膚和網紅濾鏡感。

## 功能

| 面板 | 參數 |
| --- | --- |
| 白平衡 | 色溫、色調 |
| 色調 | 曝光度、對比、亮部、陰影、白色、黑色 |
| 外觀 | 紋理、清晰度、去朦朧、細節飽和度（保護膚色）、飽和度 |
| 細節 | 銳利化 |
| HSL | 紅／橙／黃／綠／青／藍／紫／洋紅 的色相、飽和度、明度 |
| 色彩分級 | 陰影／亮部 色相與飽和度、平衡 |
| 效果 | 暗角、顆粒 |

### 遮罩（局部調整）

| 遮罩 | 用法 |
| --- | --- |
| 筆刷 | 在照片上塗抹，可調大小／羽化／流量，按住 Alt 或切到「擦除」可擦掉；`[` `]` 調整筆刷大小 |
| 線性漸層 | 拖曳畫出漸層（起點完全套用 → 終點不套用），可拖曳端點 |
| 放射狀漸層 | 從中心往外拖曳（Shift 畫橢圓），拖曳中心移動、拖曳邊緣縮放，可調羽化 |
| 顏色範圍 | 用「滴管」點照片上的顏色，選取相近顏色的區域 |
| 明度範圍 | 只選取某個亮度區間（例如只調亮部或暗部） |
| 快速選取 | 天空、膚色、主體（中央）、四周 |

- 任何遮罩都能再加上「顏色範圍」或「明度範圍」限制（交集），也可以反轉、調整遮罩強度、隱藏。
- 每個遮罩有自己的局部滑桿：色溫、色調、曝光、對比、亮部、陰影、白色、黑色、紋理、清晰度、去朦朧、飽和度、銳利度。
- 勾選「顯示疊加」（快捷鍵 `O`）會用紅色顯示遮罩範圍。
- 遮罩只依「位置、顏色、亮度」選取，**不使用 AI 分割**，也不會產生任何新內容。
  「主體」是畫面中央的放射範圍，可以自己拖曳到人物的位置。

用說的也可以操作遮罩：

| 你說的話 | 會做的事 |
| --- | --- |
| 只把天空壓暗一點 | 建立天空遮罩，遮罩內曝光 − |
| 選取膚色，提亮一點 | 建立膚色遮罩，遮罩內曝光 + |
| 針對四周暗一點 | 建立四周遮罩（反轉的放射狀） |
| 新增放射狀遮罩／加一個筆刷遮罩 | 建立對應的遮罩 |
| （選取遮罩時）再暖一點 | 調整目前選取的遮罩 |
| 反轉遮罩／刪除這個遮罩／顯示遮罩 | 遮罩操作 |
| 回到整體調整 | 離開遮罩，之後的指令改回整張照片 |

### RAW 檔

支援各家相機 RAW：Canon（CR2、CR3）、Nikon（NEF）、Sony（ARW）、Fujifilm（RAF）、Olympus／OM（ORF）、
Panasonic（RW2）、Pentax（PEF）、Leica／通用（DNG）等。

- 使用 [LibRaw](https://www.libraw.org/)（WebAssembly 版）在瀏覽器中解碼，**照片不會上傳**。
- 以 16 位元解碼、半浮點精度處理，大幅拉陰影或救亮部時比 JPEG 平滑、不易出現色階斷層。
- 預設套用相機白平衡、sRGB 色彩與亮部重建，之後可用色溫／色調等滑桿調整。
- 若 LibRaw 不支援某個（很新的）機型，會自動改用 RAW 檔內嵌的全尺寸 JPEG 預覽，並在訊息中告知。
- 解析度超過顯示卡紋理上限（多半是 8192 px 以上）時，會以半尺寸解碼。

另外還有：即時直方圖、按住看原圖（或按住 `\` 鍵）、步驟記錄、復原／重做（Ctrl+Z）、
風格預設（日系清新、電影感、復古底片、人像柔和、黑白經典、風景通透）、以原始解析度輸出 JPEG。

## 啟動

需要 Node.js 18 以上。

```bash
npm install
npm start
# 打開 http://localhost:3000
```

### 啟用 Claude 語意理解（建議）

沒有設定金鑰時，會使用內建的**離線中文解析器**，常見說法都能用
（「亮一點」「對比強一點」「顏色偏黃」「天空藍一點」「膚色太黃」「加一點暗角」「對比加20」「飽和度調到-30」「復原」……）。

想要能理解更自由、更抽象的描述（例如「想要秋天午後那種慵懶的感覺」「讓照片像早晨的陽光灑進來」），
請設定 Anthropic API 金鑰再啟動：

```bash
export ANTHROPIC_API_KEY=你的金鑰
npm start
```

啟用後，Claude 會同時參考目前的參數、照片的小預覽圖與亮度統計來決定數值。
金鑰只存在伺服器端，不會傳到瀏覽器。可用 `CLAUDE_MODEL` 環境變數更換模型。

### 語音輸入

點左下角的麥克風按鈕開始說話，說完會自動套用。
語音辨識使用瀏覽器內建的 Web Speech API（語言設為 `zh-TW`），建議使用 **Chrome、Edge 或 Safari**；
Firefox 不支援，可以直接打字。

## 指令範例

| 你說的話 | 會做的事 |
| --- | --- |
| 太暗了 | 曝光 +、陰影微提 |
| 提亮陰影、壓暗亮部 | 陰影 +、亮部 − |
| 暖一點亮一點 | 色溫 +、曝光 + |
| 顏色偏黃 | 色溫 −（修正色偏） |
| 天空藍一點 | 藍色飽和 +、藍色明度 − |
| 膚色紅潤一點／膚色太黃 | 只調整紅、橙色的 HSL |
| 皮膚柔一點 | 紋理 −（有上限，不會變塑膠臉） |
| 對比加 20／清晰度調到 30 | 精確數值 |
| 飽和度不要太高 | 飽和度 − |
| 來點電影感／日系一點 | 套用風格 |
| 復原／重做／全部重置 | 歷史操作 |

## 限制

- 一般圖片支援瀏覽器能解碼的格式（JPEG、PNG、WebP，Safari 可讀 HEIC）；TIFF 目前不支援。
- 單張照片長邊上限依顯示卡而定（最多 8192 px），超過會等比縮小（RAW 以半尺寸解碼）。
- 輸出為 8 位元 JPEG。
- RAW 解碼需要透過 `npm start` 啟動的伺服器（LibRaw 由伺服器提供），不能直接雙擊 HTML 開啟。

## 開發

```bash
npm test   # 測試離線中文解析器（含遮罩指令）
```

- `public/js/engine.js`：WebGL 修圖引擎（整體＋遮罩局部調整的 shader）
- `public/js/masks.js`：遮罩資料、筆刷點陣化
- `public/js/raw.js`：RAW 解碼（LibRaw WebAssembly）與內嵌預覽備援
- `public/js/parser.js`：離線中文指令解析
- `public/js/params.js`：參數與預設
- `public/js/app.js`：介面、語音、歷史記錄
- `server.js`：靜態伺服器 + Claude 語意理解 API
